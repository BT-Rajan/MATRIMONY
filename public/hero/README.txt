Drop images here (jpg, jpeg, png, webp, avif, gif) - they appear in the home-page hero slider automatically. No rebuild needed.
Images show in file-name order (name them 01-..., 02-... to control the order).

public/hero/            -> shown on every device
public/hero/mobile/     -> phones only (use portrait images, e.g. 1080x1920)
public/hero/tablet/     -> tablets only
public/hero/desktop/    -> laptops/desktops only (use wide images, e.g. 1920x1080)
If a device folder is empty, the images in public/hero/ are used for that device.
